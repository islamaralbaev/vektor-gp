# Vektor GP

Brauzerda ishlaydigan ochiq g'ildirakli poyga o'yini.

## O'ynash

### Windows (eng oson)
1. [Node.js](https://nodejs.org) o'rnatilgan bo'lsin.
2. **`Oyinni_boshlash.bat`** faylini ikki marta bosing.
3. Brauzer o'zi ochiladi: `http://localhost:5173/`

O'yinni yopish uchun qora oynani yoping.

### Terminal orqali
```
npm start
```

> `index.html` faylini to'g'ridan-to'g'ri ikki marta bosib ochmang, chunki brauzer
> `models/` va `draco/` fayllarini `file://` orqali yuklashga ruxsat bermaydi.
> O'yin albatta server orqali ochilishi kerak (yuqoridagi usullar).

## LAN multiplayer
Server ishga tushganda oynada `Tarmoq: http://...:5173/` manzili chiqadi.
Shu Wi‑Fi/tarmoqdagi boshqa kompyuterlar shu manzilni brauzerda ochishi mumkin.
